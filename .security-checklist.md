# Security Checklist for aws-ms-eks-reference

This checklist helps maintain security best practices for the EKS reference implementation.

## Regular Security Maintenance (Monthly)

### Version Updates
- [ ] Check for Kubernetes version updates in AWS EKS console
- [ ] Review PostgreSQL version updates and security patches
- [ ] Update AWS Load Balancer Controller to latest version
- [ ] Check Lambda runtime versions for security updates

### CloudFormation Template Security
- [ ] Run `cfn-lint` on all CloudFormation templates
- [ ] Run `cfn-nag` for security analysis
- [ ] Review IAM policies for principle of least privilege
- [ ] Check for hardcoded credentials or secrets

### Container and Image Security
- [ ] Enable ECR image scanning
- [ ] Review container base images for vulnerabilities
- [ ] Update container images to latest security patches
- [ ] Scan third-party container images before deployment

### Network Security
- [ ] Review security group rules
- [ ] Audit VPC flow logs for unusual traffic patterns
- [ ] Verify encryption in transit and at rest
- [ ] Check for publicly accessible resources

### Monitoring and Compliance
- [ ] Review AWS Security Hub findings
- [ ] Check AWS GuardDuty alerts
- [ ] Audit CloudTrail logs for suspicious activity
- [ ] Review AWS Config compliance rules

## Security Tools Integration

### Recommended CI/CD Security Checks
```bash
# Install security tools
pip install cfn-lint cfn-nag

# Lint CloudFormation templates
cfn-lint cloudformation/*.yml cloudformation/*.yaml

# Security analysis
cfn_nag_scan --input-path cloudformation/

# Check for secrets
git-secrets --scan
```

## Incident Response

### Security Incident Checklist
1. [ ] Isolate affected resources
2. [ ] Enable detailed logging
3. [ ] Document timeline and impact
4. [ ] Apply security patches
5. [ ] Review and update security measures

### Emergency Contacts
- AWS Support: Contact through AWS Console
- Security Team: Update with your organization's contact
- Infrastructure Team: Update with your organization's contact
